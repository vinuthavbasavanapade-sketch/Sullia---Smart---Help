# Sullia Smart Help

Sullia Smart Help is a website designed to help people in Sullia report and share local problems easily.

## Features
- Report road damage
- Report water problems
- Report street dog issues
- Report garbage problems
- Report street light problems
- Submit complaints with location and description

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase Firestore

## Project Area
Sullia, Karnataka, India

## Project Goal
To make it easier for people in Sullia to report local problems through one simple website.
